# ArchiSpotter 🌿

Versión web para compartir con GitHub Pages.

## Publicación
1. Crear un repositorio **público** en GitHub, por ejemplo `ArchiSpotter`.
2. Subir **todos los archivos de esta carpeta a la raíz** del repositorio (`index.html`, `manifest.webmanifest` y los tres PNG).
3. En **Settings → Pages**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.
4. Abrir `https://TU-USUARIO.github.io/ArchiSpotter/` una vez publicado.

## Instalar en celular
- iPhone: abrir con Safari → Compartir → Añadir a pantalla de inicio.
- Android: abrir con Chrome → menú → Añadir a pantalla de inicio o Instalar aplicación (según navegador).

**Notas:** el mapa, fotos y recursos externos necesitan conexión; GPS y voz dependen de permisos y compatibilidad del navegador. El usuario `user` y la contraseña `user123` son credenciales de demostración implementadas en el cliente, **no protegen datos privados**. Evitar publicar información personal en el repositorio.
